# pairwise-subtitle-wrap

字幕在 21:9 屏幕上被切成两行，断行按固定字符数算，中文和英文混排时一行塞不下；标点出现在行首，句号被单独挤到下一行；字体宽度按等宽估算，实际字体是比例字体，长单词溢出安全区；底部安全区按 16:9 算，超宽屏上字幕压到画面边缘；两行字幕的显示时长按字符数平分，第二行还没读完就消失；相邻字幕时间重叠 200ms，两行同时出现；字幕锚点固定在左下角，缩放后整体偏移；双语字幕上下顺序颠倒，原文跑到了译文下面；字幕位置按像素写死，4K 输出时字号没跟着放大；导出 SRT 时换行符被写成字面量 \n，播放器显示成一行。media/subtitle_wrap.py 是核心，tests/test_subtitle_wrap.py 15个红。要修的是：按像素宽度断行；语言断行规则；标点禁则；实际字体测量；按画幅安全区；按阅读速度定时长；重叠去重；锚点归一化；按分辨率缩放；导出校验。

## 运行

```bash
python -m pytest tests -q
```
